# COGITATOR BROWSER v4.2 — "INFINITE MIND"
## The browser that does EVERYTHING

---

## Feature 1: Notes with AI ("Cogitator Memoria")
- Встроенный блокнот с markdown
- AI-автодополнение через Ollama
- Организация по папкам/тегам
- Поиск по заметкам
- Синхронизация с page context (сохранить страницу как заметку)

## Feature 2: Built-in Terminal ("Machine Console")
- xterm.js в боковой панели
- Shell: bash/zsh/pwsh
- Работа с файловой системой
- Интеграция с командами браузера

## Feature 3: Split View ("Dual Cogitator")
- Две вкладки рядом (как Vivaldi)
- Перетаскивание для разделения
- Resize divider

## Feature 4: Tree-Style Bookmarks Sidebar ("Library of Forge")
- Боковая панель с древовидными закладками
- Как у Opera/Vivaldi
- Drag & drop организация

## Feature 5: RSS Reader with AI ("Omnissiah Feed")
- Подписка на RSS/Atom
- AI-суммаризация статей
- Категории, favorites
- Обновление в фоне

## Feature 6: Screenshot Tool ("Optical Capture")
- Скриншот всей страницы
- Скриншот выделенной области
- Аннотации: стрелки, текст, обрезка
- Сохранение / копирование в буфер

## Feature 7: Color Picker from Page ("Spectral Analyzer")
- Пипетка цвета со страницы
- История выбранных цветов
- Форматы: HEX, RGB, HSL
- Копирование в clipboard

## Feature 8: File Manager ("Archive of Mars")
- Локальный файловый менеджер
- Копировать, перемещать, удалять
- Превью картинок
- Интеграция с скачиваниями
